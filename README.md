# Home and Hearth Baker — update files

Home and Hearth Baker checks this repository when a baker clicks **Settings → Check for updates**.

- `updates.json` — the list of the newest program version and state rule files, signed by Home and Hearth Press (`updates.json.sig`). The program refuses any list whose signature doesn't match.
- `rules/` — state rule files offered as updates.
- Installers are attached to this repository's Releases.

The program's code is kept in a separate, private repository. Nothing here contains customer information.
